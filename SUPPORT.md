# Support

Thanks for using an Iwwwan-labs project. Here is how to get help.

## Where to ask

| I need to... | Go to |
| --- | --- |
| Report a bug | Open a bug report using the repository's issue template |
| Request a feature | Open a feature request using the repository's issue template |
| Ask a usage question | Open a discussion, or an issue if discussions are disabled |
| Report a security issue | Follow [SECURITY.md](SECURITY.md) — do not open a public issue |
| Report a Code of Conduct issue | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before opening an issue

- Search existing issues and discussions — your question may already be answered.
- Read the repository's `README` and any documentation in `docs/`.
- Include the version or commit, your environment, and the exact steps you took.

## Response expectations

This is a small team. We triage issues during business hours and aim to respond
within a few business days. Security reports are prioritized, as described in
[SECURITY.md](SECURITY.md).

## Commercial support

For paid engagements, partnerships, or custom development, contact us through the
organization profile at https://github.com/Iwwwan-labs.
